## 一、不可违背的产品铁律（修改 / 回退前必查红线）

> 以下条目均为用户明确确认过的核心体验规范。**任何后续重构或 `revert` 操作都绝不允许破坏或顺手回退以下任何一条！**

1. **【红线 · 视觉】被拎起时的前臂必须和坐着时的前臂保持完全一致的外观与配色**
   - 拖拽拎起状态下的前臂（`drawDragLimb` 非背侧前臂）必须严格复刻坐姿（`drawIdleFrontLeg`）的绘制顺序与材质逻辑：
     1. 肩部从透明平滑渐隐（`0.04 → 0.32`）过渡到 `palette.legs`（或胸毛底色规则一致）；
     2. 完整映射叠加皮肤自定义 `leftArm` / `rightArm` 区域与花纹（如三色柯基 `mori-corgi-sanse` 的黑段/白爪袖）；
     3. 再绘制 `palette.paws` 爪套与爪缝线条。
   - **三端（macOS / Windows / Linux）及网页工坊必须保持一致**，绝不允许出现“坐着白转黑转白、拎起来变成黑转棕”之类的割裂。
   - **回退拖拽姿态时，绝不允许把前臂配色统一修复一起回退丢掉！**

2. **【红线 · 交互】拖拽拎起姿态与交互规范**
   - **默认姿态**：保持经典**正面拎起长猫**样式（`v1.5.2` / `v1.5.4` 形态，携带键盘与鼠标/数位板），不要擅自改成 3/4 侧身拱背或出现双下巴、后颈峰遮挡耳朵。
   - **点击即揪后颈**：按下拖拽时，窗口应随 `scruffDrag` 平滑将小猫后颈（`scruffPinchCanvasPoint`）对齐到鼠标光标位置；惯性速度取纯鼠标位移，轻点/双击不可乱跳。
   - **听歌保留耳机**：听歌触发 2.5D 耳机与飘动音符时，拖拽期间必须继续绘制 `drawMusicHeadphones`（锚定至 `headCenter` 随摆动自然贴合），不可消失。

3. **【红线 · 性能】喷枪（Airbrush）等笔刷渲染性能不可回退**
   - 喷枪笔画会沿路径密集盖章（`stepDist = max(1.4, radius * 0.34)`），严禁每帧逐点实时计算径向渐变或每帧缓存全未命中：
     - macOS：必须使用按颜色缓存的 64×64 预烘焙 `CGImage` 印章；
     - Linux：必须使用按颜色缓存的 64×64 `cairo_surface_t*` 印章；
     - Windows：使用缓存的 64×64 PARGB 印章 + `InterpolationModeBilinear`（禁止软光栅 `HighQualityBilinear`）。

4. **【红线 · 跨端一致性】四端坐标源与发版顺序**
   - `shared/rig.json` 是头部与身体坐标换算参数的唯一来源；改参数必须先改 `shared/rig.json` → 跑 `python3 scripts/gen-rig.py` → 跑 `bash scripts/check-rig.sh`。
   - 任何核心修复与交互改动必须同步覆盖 **macOS (`Sources/`)、Windows (`windows/src/`)、Linux (`linux/src/`)** 三端；修改版本号必须同步更新 5 处：`Resources/Info.plist`、`windows/resource.rc`、`windows/app.manifest`、`windows/src/main.cpp`、`linux/src/main.cpp`。
   - 若皮肤格式或上限升级（如 `formatVersion 2`、`minAppVersion`），必须**先发布桌宠新版本，再上线皮肤工坊**。

5. **【红线 · 提交前校验】**
   - macOS 本地/CI 提交前必须通过：`bash scripts/check-rig.sh`、`bash scripts/check-skins.sh`、`bash scripts/check-eye-closure.sh`、`tests/skin-format/parse_test.cpp`、`./build.sh`。
   - 皮肤工坊提交前必须通过：`node scripts/validate-community.mjs`。
