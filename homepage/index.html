去 GitHub 提问
KuroCat 会记录或上传我按了什么键吗？

不会。所有键盘与鼠标信号只在本地内存里驱动小猫动画与计数，不写按键日志，不上传任何按键内容。只有检查更新时会向官方下载站查询最新版本号。全部源码以 MIT 协议公开，任何人都可以审计。

KuroCat 和传统 Bongo Cat 有什么区别？

KuroCat 用 Swift、Win32 C++ 与 GTK3 Cairo 原生开发，Windows 单文件约 850 KB，覆盖 macOS、Windows、Linux 与统信 UOS。除了全键无冲拍键，还有 2.5D 球面转头、捕猎圆瞳、数位板握笔、OBS 透明与绿幕模式、拎后颈惯性拖拽，以及在线皮肤工坊。

怎么把 KuroCat 加到 OBS、抖音直播伴侣或 B 站直播姬？

右键小猫或托盘图标，在设置里开启「OBS 透明窗口捕获」或「OBS 绿幕模式（#00FF00）」，然后在直播软件里添加窗口采集即可。开启 OBS 模式后会自动停用全屏隐藏，画面不会意外消失。

开启鼠标穿透后，找不到设置菜单怎么办？

透明区域本来就会穿透；开启完全穿透后，点顶部菜单栏（macOS）或右下角托盘（Windows / Linux）里的 KuroCat 图标即可打开菜单。macOS 按住 Option、Windows 按 Ctrl + Alt + Shift + P 也能随时唤起。

macOS 提示无法打开，或者打字没反应？

第一次打开时，右键 KuroCat.app 选「打开」并在弹窗里再确认一次；然后到「系统设置 → 隐私与安全性 → 输入监控」勾选 KuroCat，从菜单栏重启一次即可。

Windows 提示 SmartScreen 拦截，安全吗？

个人开源软件刚发布新版时，容易被 SmartScreen 提示为不常见的下载。核对本页与 GitHub Release 的 SHA-256 一致后，选择「更多信息 → 仍要运行」即可，也可以拉取源码自己编译。

统信 UOS 和银河麒麟能直接安装吗？

可以。Linux 包在 Debian 10（glibc 2.28）环境编译，兼容统信 UOS 20 与银河麒麟 V10，提供 x86_64 与 ARM64 两种架构。不方便输入管理员密码时，推荐用 tar.gz 免 sudo 安装脚本。

怎么把自家猫做成皮肤并分享？

打开 KuroCat 皮肤工坊，上传照片自动分析毛色，用钢笔工具画花纹分区，再加上配饰贴纸。导出的 .kurocat 文件直接拖到桌面小猫身上就能生效，也可以投稿到社区广场。
